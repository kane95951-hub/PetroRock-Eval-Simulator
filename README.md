# PetroRock-Eval Digital Laboratory v2

Refonte pédagogique du simulateur Rock-Eval.

## Fonctionnalités
- S1 indépendant, S2/S3, HI/OI/PI/PY et Tmax détecté depuis S2.
- Contrôle qualité, avertissements et unités.
- Pyrogramme paramétrable : bruit, asymétrie, épaule/double pic.
- Digital Rock-Eval Laboratory 250–600 °C avec mode guidé/examen.
- Import CSV/Excel, validation, analyse par profondeur, HI/OI et comparaison A/B.
- Rapports PDF, historique local, quiz/défis, bibliothèque scientifique.
- PWA, responsive, clair/sombre.

## Formules
HI=S2/TOC×100; OI=S3/TOC×100; PI=S1/(S1+S2); PY=S1+S2. Tmax est le maximum de la courbe S2 simulée.

## Limites
Modèle numérique pédagogique. Ne remplace pas un appareil Rock-Eval, une mesure de laboratoire ni un protocole analytique validé. Les classifications sont indicatives.
